# 에셋 참조와 소프트 포인터

> 에셋을 메모리에 올리는 시점을 제어하는 방법. 무거운 에셋을 "필요할 때만" 로드해서 메모리와 로딩 속도를 최적화한다.

---

## 에셋을 가져오는 3가지 방식

|방식|방법|시점|
|---|---|---|
|**프로퍼티 참조**|`UPROPERTY(EditAnywhere)` + 블루프린트에서 할당|직접|
|**생성 시간 참조**|`ConstructorHelpers::FObjectFinder<T>`|생성자 단계|
|**간접 프로퍼티 참조**|`TSoftObjectPtr` / `TSoftClassPtr`|원하는 시점|

### 생성 시간 참조 보충

```cpp
ConstructorHelpers::FObjectFinder<UStaticMesh> MeshFinder(TEXT("경로"));
```

- 생성자 단계에서 경로로 에셋을 찾음
- 메모리에 있으면 로드, 없거나 오류면 `nullptr` 반환
- 이 값은 [[CDO (Class Default Object)]]에 기록됨

---

## 하드 참조 vs 소프트 참조

### 하드 참조 (Hard Reference)

캐릭터가 사과를 참조하면, **캐릭터가 로드되는 순간 사과도 반드시 함께 로드**된다.

- ✅ 장점: 참조된 에셋을 바로 사용 가능
- ❌ 단점: 줄줄이 연결된 에셋이 한꺼번에 메모리에 올라감

> 캐릭터가 무기 수십 개를 하드 참조하면, 캐릭터 하나 소환에 무기 전체가 메모리를 점유한다.

### 소프트 참조 (Soft Reference)

에셋의 **경로 정보만** 가지고 있다. 실제 사용 전까지는 로드되지 않는다.

- ✅ 당장 필요 없는 데이터는 로드 안 함 → 로딩 속도, 메모리 개선
- ✅ 비동기 로드로 프레임 드랍 방지 가능
- 적합한 경우: 인벤토리의 수백 개 아이콘, 특정 스테이지에만 등장하는 몬스터, 고해상도 텍스처/사운드, 대규모 맵의 레벨 스트리밍

---

## 선언 방식

```cpp
// 오브젝트(에셋 인스턴스)를 가리킬 때
UPROPERTY(EditAnywhere, Category = "Loading")
TSoftObjectPtr<UStaticMesh> MeshToLoad;

// 클래스를 가리킬 때
UPROPERTY(EditAnywhere, Category = "Loading")
TSoftClassPtr<AActor> ActorClassToLoad;
```

> Object와 Class 차이만 있을 뿐, 구현(로드) 방법은 동일하다. (`TObjectPtr` vs [[TSubclassOf]] 관계와 유사)

---

## 동기 로드 — 끝날 때까지 멈춤

"원할 때 로드하되, 다 끝날 때까지 메인 스레드는 멈춰 있어."

```cpp
void AMyActor::LoadWithSoftPtr()
{
    if (MySoftMesh.IsNull()) return;

    UStaticMesh* FinalMesh = nullptr;

    if (MySoftMesh.IsValid())
    {
        // 이미 로드됨 → 즉시 참조
        FinalMesh = MySoftMesh.Get();
    }
    else
    {
        // 아직 로드 안 됨 → 동기 로드 (여기서 멈춤)
        FinalMesh = MySoftMesh.LoadSynchronous();
    }

    if (FinalMesh) { /* 사용 */ }
}
```

|함수|역할|
|---|---|
|`IsNull()`|경로 자체가 없는지|
|`IsValid()`|이미 메모리에 로드되어 있는지|
|`Get()`|로드된 에셋 꺼내기|
|`LoadSynchronous()`|동기 로드 실행|

## 비동기 로드 — 백그라운드에서

"게임은 게임대로, 로딩은 로딩대로." [[콜리전과 Trace]]의 비동기 Trace와 같은 원리 (서브 스레드 활용).

```cpp
#include "Engine/AssetManager.h"
#include "Engine/StreamableManager.h"

void AMyActor::LoadWithSoftPtr()
{
    if (MySoftMesh.IsNull()) return;

    if (MySoftMesh.IsValid())
    {
        OnLoadCompleted();  // 이미 로드됨
    }
    else
    {
        // 에셋 매니저에게 비동기 로드 요청
        FStreamableManager& Streamable = UAssetManager::GetStreamableManager();
        Streamable.RequestAsyncLoad(
            MySoftMesh.ToSoftObjectPath(),
            FStreamableDelegate::CreateUObject(this, &AMyActor::OnLoadCompleted)
        );
    }
}

// 로드 완료 시 엔진이 자동 호출
void AMyActor::OnLoadCompleted()
{
    UStaticMesh* FinalMesh = MySoftMesh.Get();
    if (FinalMesh) { /* 메시 적용 */ }
}
```

> 완료 콜백 연결에 [[델리게이트]](https://claude.ai/chat/%60FStreamableDelegate%60)를 사용한다.

## 로드 결과물은 "객체가 아니다"

최종적으로 받는 것은 `UClass*` 또는 에셋 그 자체. **인스턴스가 아니다.**

"로드했으니 이제 알아서 써!"라는 상태. 스폰하거나 컴포넌트에 넣어서 사용하면 된다.

```cpp
UClass* LoadedClass = MySoftClass.LoadSynchronous();
GetWorld()->SpawnActor<AActor>(LoadedClass, Location, Rotation);
```
