# 아이템 매니저 실전 예시

> [[서브시스템]] + [[데이터 관리 - DataTable과 DataAsset|DataAsset]] + [[델리게이트]]를 종합한 아이템 로딩 매니저. 지금까지 배운 개념들이 어떻게 맞물리는지 보여주는 실전 통합 예제.

---

## 구성 요소 3가지

|클래스|상속|역할|
|---|---|---|
|`ItemManagerSubsystem`|`UGameInstanceSubsystem`|아이템 로드/언로드 중앙 관리|
|`MyItemDataAsset`|`UPrimaryDataAsset`|아이템 데이터 정의|
|`ItemManagerTestCharacter`|`ACharacter`|아이템을 요청하고 장착|

전체 흐름: **캐릭터가 매니저에 로드 요청 → 매니저가 비동기 로드 → 완료되면 델리게이트로 알림 → 캐릭터가 장착**

---

## 1. ItemManagerSubsystem

GameInstance 수명을 가지므로 게임 내내 살아있다. 아이템 로딩의 중앙 허브.

```cpp
DECLARE_DYNAMIC_MULTICAST_DELEGATE_OneParam(FOnItemLoaded, FPrimaryAssetId, AssetId);

public:
    virtual void Initialize(FSubsystemCollectionBase& Collection) override;

    UFUNCTION(BlueprintCallable)
    void RequestAsyncLoadItem(FPrimaryAssetId AssetId);

    UFUNCTION(BlueprintCallable)
    UMyItemDataAsset* GetItemData(FPrimaryAssetId AssetId);

    UFUNCTION(BlueprintCallable)
    void UnloadItem(FPrimaryAssetId AssetId);

    UPROPERTY(BlueprintAssignable)
    FOnItemLoaded OnItemLoaded;  // 로드 완료 방송

private:
    void OnLoadCompleted(FPrimaryAssetId AssetId);

    // 핸들 보관 → GC 방지 (TMap으로 여러 아이템 관리)
    TMap<FPrimaryAssetId, TSharedPtr<FStreamableHandle>> LoadingHandles;
```

### 로드 요청

```cpp
void UItemManagerSubsystem::RequestAsyncLoadItem(FPrimaryAssetId AssetId)
{
    if (!AssetId.IsValid()) return;

    // 이미 로드 중/완료면 중복 방지
    if (LoadingHandles.Contains(AssetId) && LoadingHandles[AssetId]->IsActive())
        return;

    UAssetManager& Manager = UAssetManager::Get();
    TSharedPtr<FStreamableHandle> Handle = Manager.LoadPrimaryAsset(
        AssetId, TArray<FName>(),
        FStreamableDelegate::CreateUObject(this, &UItemManagerSubsystem::OnLoadCompleted, AssetId)
    );

    LoadingHandles.Add(AssetId, Handle);  // 핸들 보관 필수
}
```

> 핸들을 [[TMap]]에 보관하지 않으면 로딩 중 [[댕글링 포인터와 안전한 참조|핸들이 GC되어]] 로드가 취소된다.

### 로드 완료 → 방송

```cpp
void UItemManagerSubsystem::OnLoadCompleted(FPrimaryAssetId AssetId)
{
    if (OnItemLoaded.IsBound())
    {
        OnItemLoaded.Broadcast(AssetId);  // "이 아이템 다 로드됐어!" 방송
    }
}
```

### 언로드

```cpp
void UItemManagerSubsystem::UnloadItem(FPrimaryAssetId AssetId)
{
    if (LoadingHandles.Contains(AssetId))
    {
        LoadingHandles.Remove(AssetId);              // 핸들 제거 → GC 대상이 됨
        UAssetManager::Get().UnloadPrimaryAsset(AssetId);
    }
}
```

## 2. MyItemDataAsset

```cpp
public:
    UPROPERTY(EditAnywhere, BlueprintReadOnly, Category = "Item")
    FPrimaryAssetType ItemType;

    UPROPERTY(EditAnywhere, BlueprintReadOnly, Category = "Stats")
    float AttackDamage;

    // 무거운 에셋은 소프트 포인터로
    UPROPERTY(EditAnywhere, BlueprintReadOnly, Category = "Visual")
    TSoftObjectPtr<USkeletalMesh> ItemMesh;

    virtual FPrimaryAssetId GetPrimaryAssetId() const override
    {
        return FPrimaryAssetId(ItemType, GetFName());
    }
```

> [[에셋 참조와 소프트 포인터|TSoftObjectPtr]]로 메시를 선언해 로드 시점을 제어한다.

## 3. ItemManagerTestCharacter

```cpp
void AItemManagerTestCharacter::EquipItem(FPrimaryAssetId ItemId)
{
    if (!ItemId.IsValid()) return;

    // 1. 서브시스템 가져오기
    UItemManagerSubsystem* ItemManager = GetGameInstance()->GetSubsystem<UItemManagerSubsystem>();
    if (!ItemManager) return;

    // 2. 완료 알림 구독 (중복 방지를 위해 AddUnique)
    ItemManager->OnItemLoaded.AddUniqueDynamic(this, &AItemManagerTestCharacter::OnEquipReady);

    // 3. 로드 요청
    ItemManager->RequestAsyncLoadItem(ItemId);
}

void AItemManagerTestCharacter::OnEquipReady(FPrimaryAssetId LoadedId)
{
    // 내가 요청한 아이템이 맞는지 확인 (여러 개 동시 로드 대비)
    if (LoadedId != ItemToEquip) return;

    UItemManagerSubsystem* ItemManager = GetGameInstance()->GetSubsystem<UItemManagerSubsystem>();
    UMyItemDataAsset* Data = ItemManager->GetItemData(LoadedId);

    if (Data)
    {
        CurrentEquippedItem = Data;
        // 실제 장착: 메시 변경, 능력치 적용 등

        // 다 썼으면 구독 해제
        ItemManager->OnItemLoaded.RemoveDynamic(this, &AItemManagerTestCharacter::OnEquipReady);
    }
}
```

## 개념 연결 정리

이 예제 하나에 여러 개념이 맞물린다:

```
서브시스템 (GameInstance 수명, GC 자동 관리)
   ├── DataAsset + AssetManager (아이템 데이터, 비동기 로드)
   ├── 소프트 포인터 (무거운 메시 로드 시점 제어)
   ├── 델리게이트 (로드 완료 알림, 느슨한 결합)
   └── TMap (여러 로딩 핸들 보관)
```

캐릭터는 "어떻게 로드되는지" 몰라도 된다. 그냥 요청하고, 완료 신호를 기다린다. 매니저는 "누가 요청했는지" 몰라도 된다. 그냥 방송한다. → 느슨한 결합의 완성형.
