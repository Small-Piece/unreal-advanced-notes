# 데미지 시스템

> 언리얼 엔진에서 데미지를 주고받는 구조. Apply(송신) → TakeDamage(수신) 패턴으로 동작하며, DamageType으로 데미지 종류를 분기한다.

---

## 데미지 함수 종류

|구분|송신 함수|데이터 구조체|활용 사례|
|---|---|---|---|
|**Any**|`ApplyDamage`|`FDamageEvent`|독, 화상, 단순 체력 감소|
|**Point**|`ApplyPointDamage`|`FPointDamageEvent`|총기(헤드샷), 칼 (타격 위치/방향 필요)|
|**Radial**|`ApplyRadialDamage`|`FRadialDamageEvent`|폭발, 충격파 (거리별 감쇄)|

> 수신은 전부 `TakeDamage`로 받는다. AActor에서 상속받아 override.

---

## 데미지 주는 쪽 (Apply)

### ApplyDamage — 단순 데미지

```cpp
UGameplayStatics::ApplyDamage(
    TargetActor,                        // 피격 대상
    10.f,                               // 데미지 양
    GetController(),                    // 가해자 컨트롤러
    this,                               // 데미지 유발 액터
    UDamageType::StaticClass()          // 데미지 타입
);
```

### ApplyPointDamage — 위치/방향 포함

[[콜리전과 Trace]]의 히트 결과를 활용:

```cpp
UGameplayStatics::ApplyPointDamage(
    HitActor,                           // 피격 대상
    50.f,                               // 데미지 양
    GetActorForwardVector(),            // 공격 방향
    HitResult,                          // FHitResult (어느 부위인가)
    GetInstigatorController(),          // 가해자
    this,                               // 유발 도구
    UMyDamageType::StaticClass()        // 데미지 타입
);
```

## 데미지 받는 쪽 (TakeDamage)

AActor에서 상속받아 override:

```cpp
// 헤더
virtual float TakeDamage(float DamageAmount, struct FDamageEvent const& DamageEvent,
    class AController* EventInstigator, AActor* DamageCauser) override;
```

```cpp
// CPP
float AMyCharacter::TakeDamage(float DamageAmount, FDamageEvent const& DamageEvent,
    AController* EventInstigator, AActor* DamageCauser)
{
    float ActualDamage = Super::TakeDamage(DamageAmount, DamageEvent, EventInstigator, DamageCauser);

    // DamageType의 CDO를 가져와서 종류 판별
    const UDamageType* DT = DamageEvent.DamageTypeClass->GetDefaultObject<UDamageType>();

    if (DT && DT->bCausedByWorld)
    {
        // 환경 데미지 (낙사, 트랩 등)
    }

    if (EventInstigator)
    {
        // 적의 공격
    }

    return ActualDamage;
}
```

> `GetDefaultObject<>()`로 [[CDO (Class Default Object)]]를 참조하는 것이 핵심. 메모리에 하나만 존재하는 원본을 가볍게 참조한다.

## DamageType — 데미지 종류 분기

데미지가 발생했을 때 "이건 어떤 종류의 데미지인가?"를 판단하는 기준.

### 기본 제공 변수

|변수|타입|설명|
|---|---|---|
|`DamageImpulse`|`float`|피격 시 밀어내는 힘|
|`DestructibleImpulse`|`float`|파괴 가능 메시에 가하는 충격량|
|`bCausedByWorld`|`bool`|월드 데미지인지 여부 (낙사, 트랩)|
|`bScaleMomentumByMass`|`bool`|무게에 따라 밀림 차등 적용|

> 이 변수들은 기능이 내장된 게 아니라 **기준값만 제시**한 것. 실제 기능은 직접 구현해야 한다.

## 커스텀 DamageType 만들기

### 1. 커스텀 클래스 생성

```cpp
UCLASS()
class UFireDamageType : public UDamageType
{
    GENERATED_BODY()
public:
    UPROPERTY(EditAnywhere, BlueprintReadOnly)
    float BurnDuration = 5.0f;

    UPROPERTY(EditAnywhere, BlueprintReadOnly)
    float ArmorPenetration = 0.2f;
};
```

### 2. TakeDamage에서 타입 분기

```cpp
float AMyCharacter::TakeDamage(float DamageAmount, FDamageEvent const& DamageEvent,
    AController* EventInstigator, AActor* DamageCauser)
{
    float FinalDamage = Super::TakeDamage(DamageAmount, DamageEvent, EventInstigator, DamageCauser);

    // CDO에서 FireDamageType 정보 가져오기
    const UFireDamageType* FireDT =
        DamageEvent.DamageTypeClass->GetDefaultObject<UFireDamageType>();

    if (FireDT)
    {
        FinalDamage *= (1.0f + FireDT->ArmorPenetration);
        ApplyBurnEffect(FireDT->BurnDuration);
    }

    CurrentHP -= FinalDamage;
    return FinalDamage;
}
```

### 3. Apply 쪽에서 커스텀 타입 지정

```cpp
UGameplayStatics::ApplyPointDamage(
    HitActor, 50.f, Direction, HitResult,
    GetInstigatorController(), this,
    UFireDamageType::StaticClass()  // 커스텀 타입 사용
);
```

## 전체 흐름 요약

```
공격자: Trace 발사
         ↓
   HitResult 획득
         ↓
   ApplyPointDamage(대상, 데미지, 방향, HitResult, 가해자, DamageType)
         ↓
피격자: TakeDamage 호출됨
         ↓
   DamageEvent.DamageTypeClass->GetDefaultObject<>()로 CDO 참조
         ↓
   타입에 따라 분기 (화상? 독? 물리?)
         ↓
   최종 데미지 적용
```
