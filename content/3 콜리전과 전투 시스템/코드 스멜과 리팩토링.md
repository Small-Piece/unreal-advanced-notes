# 코드 스멜과 리팩토링

> 코드에서 나는 "냄새" — 당장 에러는 아니지만, 방치하면 유지보수가 어려워지는 구조적 문제들

---

## 뒤엉킨 변경 (Divergent Change)

한 클래스가 **여러 이유**로 자주 수정되어야 하는 상태. 단일 책임 원칙을 위반한 것.

### ❌ 나쁜 예시 — 하나의 GameManager가 데이터도, 게임플레이도 담당

```cpp
class AGameManager : public AActor
{
    void LoadPlayerData();   // 데이터 관련
    void SavePlayerData();   // 데이터 관련
    void StartNewGame();     // 게임플레이 관련
    void SpawnEnemies();     // 게임플레이 관련
};
```

### ✅ 좋은 예시 — 맥락별로 클래스를 분리

```cpp
class UPlayerDataManager : public UGameInstanceSubsystem
{
    void LoadPlayerData();
    void SavePlayerData();
};

class UGameplayManager : public UGameInstanceSubsystem
{
    void StartNewGame();
    void SpawnEnemies();
};
```

## 샷건 수술 (Shotgun Surgery)

작은 변경 하나를 위해 **여러 클래스를 동시에 수정**해야 하는 상태. 관련 로직이 산재해 있으면 버그가 쉽게 발생하고 찾기 어렵다.

### ❌ 나쁜 예시 — 데미지 로직이 3곳에 분산

```cpp
class APlayerCharacter { void TakeDamage(float Amount); };    // 데미지 로직 1
class AWeapon { float CalculateDamage(); };                   // 데미지 로직 2
class AMyGameMode { void UpdateDamageLeaderboard(); };        // 데미지 로직 3
```

### ✅ 좋은 예시 — 데미지 관련 로직을 한 곳에 모음

```cpp
class UDamageSystem : public UObject
{
    float CalculateDamage(AWeapon* Weapon, ACharacter* Target);
    void ApplyDamage(AWeapon* Weapon, ACharacter* Target);
    void UpdateDamageLeaderboard(ACharacter* Damager, ACharacter* Target, float Amount);
};
```

## 기능 편애 (Feature Envy)

어떤 함수가 **자기 객체보다 남의 객체 데이터**와 더 많이 소통하는 상태. 그 함수는 데이터가 있는 곳으로 옮겨야 한다.

### ❌ 나쁜 예시 — DamageCalculator가 Character의 데이터를 잔뜩 가져다 씀

```cpp
class UDamageCalculator : public UObject
{
    float CalculateDamageReduction(AMyCharacter* Character, float Damage)
    {
        float HealthPercent = Character->GetHealth() / Character->GetMaxHealth();
        float ArmorFactor = Character->GetArmor() * 0.1f;
        return Damage * (1.0f - ArmorFactor * HealthPercent);
    }
};
```

### ✅ 좋은 예시 — 캐릭터가 자기 데이터로 직접 계산

```cpp
class AMyCharacter : public ACharacter
{
    float CalculateDamageReduction(float Damage) const
    {
        float HealthPercent = Health / MaxHealth;
        float ArmorFactor = Armor * 0.1f;
        return Damage * (1.0f - ArmorFactor * HealthPercent);
    }
};
```
