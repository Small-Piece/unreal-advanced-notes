# 콜리전 시스템

> 언리얼 엔진에서 물체가 서로 충돌하거나 겹치는 것을 제어하는 시스템. 눈에 보이는 메시가 막아주는 게 아니라, **콜리전**이 충돌 처리를 담당한다.

---

## 상호작용 결과표

두 오브젝트가 만났을 때의 결과:

|A \ B|Block|Overlap|Ignore|
|---|---|---|---|
|**Block**|Block|Overlap|Ignore|
|**Overlap**|Overlap|Overlap|Ignore|
|**Ignore**|Ignore|Ignore|Ignore|

> **Ignore가 최우선.** Ignore가 하나라도 있으면 무조건 Ignore. 이 우선순위는 [[콜리전과 Trace]]에서도 동일하게 적용된다.

### 콜리전 우선순위

```
Ignore > Overlap > Block
```

상위 우선순위에서 하위로는 강제 변경 불가. Block → Overlap 변경은 가능하지만, Ignore → Block 변경은 불가능.

## Object Channel과 Preset

프로젝트 세팅 → 콜리전에서 설정.

### Object Channel — "나는 누구인가"

오브젝트의 정체를 나타내는 이름표. 기본 제공되는 것 외에 커스텀 채널을 만들 수 있다.

예: `Barrier`(결계)라는 오브젝트 채널을 만들고, 기본 반응을 Block으로 설정하면 → 다른 모든 프리셋에서 Barrier를 Block 처리하게 된다.

### Preset — "나는 다른 애들과 이렇게 상호작용하겠다"

오브젝트 채널 + 각 채널별 반응(Block/Overlap/Ignore)을 묶어서 미리 저장해 놓은 것.

- 새 프리셋을 만들어서 특정 오브젝트 타입별 반응을 세밀하게 설정 가능
- 액터의 디테일 패널에서 프리셋을 선택하면 해당 설정이 적용됨

### Trace Channel

Camera, Visibility 등 [[콜리전과 Trace|Trace]]용 채널. 오브젝트 간 충돌이 아니라, 레이캐스트가 이 오브젝트를 감지할 수 있는지를 결정한다.

예: Camera 트레이스 채널을 Block으로 설정하면, 카메라 붐(셀카봉)이 이 오브젝트에 막혀서 줄어든다.

## 단순 콜리전 vs 복합 콜리전

스태틱 메시의 충돌 모양을 결정하는 설정.

|구분|단순 콜리전 (Simple)|복합 콜리전 (Complex)|
|---|---|---|
|모양|박스, 캡슐, 구 등 단순한 도형|메시 모양 그대로 (폴리곤 단위)|
|성능|빠름 (폴리곤 적음)|느림 (폴리곤 많음)|
|정밀도|낮음|높음|

### Collision Complexity 옵션

|설정|의미|
|---|---|
|Project Default|프로젝트 세팅의 전체 설정값 사용|
|Simple And Complex|이동 충돌은 단순, 트레이스 히트는 복합|
|Use Simple Collision Only|단순 콜리전만 사용|
|Use Complex Collision Only|복합 콜리전만 사용|

---

## 콜리전 설정 위치의 우선순위

스태틱 메시 에디터 안의 콜리전 프리셋 값이 기본값이지만, 레벨 에디터 디테일 창에서 설정하면 그 값으로 **덮어씌워진다**. (Default = 메시 에디터 값 사용)
