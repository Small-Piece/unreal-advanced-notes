# 오브젝트 풀링

> 객체를 생성/삭제하는 대신, 미리 만들어 둔 객체를 재사용하는 최적화 디자인 패턴. 잦은 메모리 할당/해제 비용을 줄인다.

---

## 왜 쓰나?

게임에서 객체를 동적으로 생성·삭제하는 데는 생각보다 큰 비용이 든다.

- **생성**: 메모리 초기화 + 할당 과정을 거침
- **삭제**: 시스템이 사용한 메모리 공간을 정리

이게 짧은 순간에 많이 일어나면 CPU 부하가 쌓이고, 한꺼번에 메모리를 정리하면 순간 **프레임 드랍**이 생긴다.

> 총알을 스폰하는 게임에서 총알을 난사하면, 생성·삭제가 폭발적으로 반복되어 게임에 큰 부하가 된다.

---

## 동작 원리 (총알 예시)

```
게임 시작 시 → 모든 총알을 미리 생성해두고 보관함에서 대기
        ↓
총알 발사 → 필요한 위치로 순간이동시키고 활성화
        ↓
총알이 멀리 날아감 → 비활성화하고 보관함으로 반환
```

생성/삭제 대신 **활성화/비활성화 + 위치 이동**만 한다. 동일한 크기의 메모리 청크를 재활용하므로 빠르다.

> 앞서 [[콜리전과 Trace]]에서 "총알 대신 Trace를 쏘는" 이유와 같은 맥락의 최적화. 실제 총알 액터가 필요하면 풀링으로 비용을 낮춘다.

---

## 구성 요소 3가지

|클래스|상속|역할|
|---|---|---|
|`MyObjectPool`|`AActor`|풀 전체를 관리하는 본체|
|`PooledObject`|`UActorComponent`|각 액터에 붙어 사용 중인지 추적, 반환 요청|
|`FPooledObjectData`|구조체|어떤 액터를 몇 개 만들지 등의 설정(레시피)|

---

## FPooledObjectData — 풀 설정 레시피

```cpp
USTRUCT(BlueprintType)
struct FPooledObjectData
{
    GENERATED_BODY()

    UPROPERTY(EditAnywhere)
    TSubclassOf<AActor> ActorTemplate;  // 어떤 액터를 스폰할 것인가

    UPROPERTY(EditAnywhere)
    int PoolSize;                        // 몇 개를 스폰할 것인가

    UPROPERTY(EditAnywhere)
    bool CanGrow;                        // 부족하면 추가 생성할 것인가

    UPROPERTY(EditAnywhere)
    FString ActorName;                   // 액터 이름
};
```

> [[TSubclassOf]]로 스폰할 클래스를 안전하게 지정한다.

---

## PooledObject — 추적 컴포넌트

각 풀링 대상 액터에 붙어서, 그 액터가 사용 중인지 체크하고 반환 요청을 담당한다.

```cpp
UCLASS(ClassGroup=(Custom), meta=(BlueprintSpawnableComponent))
class UPooledObject : public UActorComponent
{
    GENERATED_BODY()

public:
    void Init(AMyObjectPool* Owner);

    UFUNCTION(BlueprintCallable)
    void RecycleSelf();                  // 스스로 풀에 반환

    UPROPERTY(VisibleInstanceOnly, BlueprintReadOnly)
    bool bIsPoolActive;                  // 현재 사용 중인지

private:
    TObjectPtr<AMyObjectPool> ObjectPool;  // 자신을 관리하는 풀

    virtual void OnComponentDestroyed(bool bDestroyingHierarchy) override;
};
```

```cpp
void UPooledObject::Init(AMyObjectPool* Owner)
{
    bIsPoolActive = false;
    ObjectPool = Owner;
}
```

## MyObjectPool — 풀 본체

### 주요 인터페이스

```cpp
DECLARE_DYNAMIC_MULTICAST_DELEGATE(FPoolerCleanupSignature);

// 풀 하나(한 종류 액터들의 모음)
USTRUCT(BlueprintType)
struct FSingleObjectPool
{
    GENERATED_BODY()
    UPROPERTY(VisibleInstanceOnly, BlueprintReadOnly)
    TArray<TObjectPtr<UPooledObject>> PooledObjects;
};

UCLASS()
class AMyObjectPool : public AActor
{
public:
    UPROPERTY()
    FPoolerCleanupSignature OnPoolerCleanup;  // 정리 신호 (델리게이트)

    UFUNCTION(BlueprintCallable)
    AActor* GetPooledActor(FString Name);     // 풀에서 액터 꺼내기

    UFUNCTION(BlueprintCallable)
    void RecyclePooledObject(UPooledObject* PoolCompRef);  // 반환

    UPROPERTY(EditAnywhere, BlueprintReadWrite)
    TArray<FPooledObjectData> PooledObjectData;  // 레시피 목록

protected:
    UPROPERTY(VisibleAnywhere, BlueprintReadWrite)
    TArray<FSingleObjectPool> Pools;             // 실제 풀 보관소
};
```

> 정리 알림에 [[델리게이트]]를, 풀 보관에 [[TArray]]를 사용한다.

### BeginPlay — 미리 생성하기

```cpp
void AMyObjectPool::BeginPlay()
{
    Super::BeginPlay();

    FActorSpawnParameters SpawnParams;
    for (int PoolIndex = 0; PoolIndex < PooledObjectData.Num(); PoolIndex++)
    {
        FSingleObjectPool CurrentPool;
        SpawnParams.Name = FName(*PooledObjectData[PoolIndex].ActorName);
        SpawnParams.NameMode = FActorSpawnParameters::ESpawnActorNameMode::Requested;
        SpawnParams.SpawnCollisionHandlingOverride = ESpawnActorCollisionHandlingMethod::AlwaysSpawn;

        for (int ObjectIndex = 0; ObjectIndex < PooledObjectData[PoolIndex].PoolSize; ObjectIndex++)
        {
            // 1. 액터 스폰
            AActor* SpawnedActor = GetWorld()->SpawnActor(
                PooledObjectData[PoolIndex].ActorTemplate,
                &FVector::ZeroVector, &FRotator::ZeroRotator, SpawnParams);

            // 2. 추적 컴포넌트 부착
            UPooledObject* PoolComp = NewObject<UPooledObject>(SpawnedActor);
            PoolComp->RegisterComponent();
            SpawnedActor->AddInstanceComponent(PoolComp);
            PoolComp->Init(this);
            CurrentPool.PooledObjects.Add(PoolComp);

            // 3. 비활성화 상태로 대기
            SpawnedActor->SetActorHiddenInGame(true);      // 안 보이게
            SpawnedActor->SetActorEnableCollision(false);  // 충돌 끄기
            SpawnedActor->SetActorTickEnabled(false);       // Tick 끄기
            SpawnedActor->AttachToActor(this, FAttachmentTransformRules::SnapToTargetNotIncludingScale);
        }
        Pools.Add(CurrentPool);
    }
}
```

### 비활성화의 3요소

대기 중인 객체는 이 세 가지를 꺼서 "존재하지만 아무 일도 안 하는" 상태로 만든다:

|함수|효과|
|---|---|
|`SetActorHiddenInGame(true)`|화면에서 숨김|
|`SetActorEnableCollision(false)`|충돌 판정 끔|
|`SetActorTickEnabled(false)`|매 프레임 갱신 끔|

활성화할 때는 이 셋을 다시 켜고 위치만 옮기면 된다.
