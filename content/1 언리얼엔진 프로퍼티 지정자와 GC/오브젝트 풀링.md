# 오브젝트 풀링

> 객체를 생성/삭제하는 대신, 미리 만들어 둔 객체를 재사용하는 최적화 디자인 패턴. 잦은 메모리 할당/해제 비용을 줄인다.

---

## 왜 쓰나?

게임에서 객체를 동적으로 생성·삭제하는 데는 생각보다 큰 비용이 든다.

- **생성**: 메모리 초기화 + 할당 과정을 거침
- **삭제**: 시스템이 사용한 메모리 공간을 정리

이게 짧은 순간에 많이 일어나면 CPU 부하가 쌓이고, 한꺼번에 메모리를 정리하면 순간 **프레임 드랍**이 생긴다.

> 총알을 스폰하는 게임에서 총알을 난사하면, 생성·삭제가 폭발적으로 반복되어 게임에 큰 부하가 된다.

---

## 동작 원리 (총알 예시)

```
게임 시작 시 → 모든 총알을 미리 생성해두고 보관함에서 대기
        ↓
총알 발사 → 필요한 위치로 순간이동시키고 활성화
        ↓
총알이 멀리 날아감 → 비활성화하고 보관함으로 반환
```

생성/삭제 대신 **활성화/비활성화 + 위치 이동**만 한다. 동일한 크기의 메모리 청크를 재활용하므로 빠르다.

> 앞서 [[콜리전과 Trace]]에서 "총알 대신 Trace를 쏘는" 이유와 같은 맥락의 최적화. 실제 총알 액터가 필요하면 풀링으로 비용을 낮춘다.

---

## 구성 요소 3가지

|클래스|상속|역할|
|---|---|---|
|`MyObjectPool`|`AActor`|풀 전체를 관리하는 본체|
|`PooledObject`|`UActorComponent`|각 액터에 붙어 사용 중인지 추적, 반환 요청|
|`FPooledObjectData`|구조체|어떤 액터를 몇 개 만들지 등의 설정(레시피)|

## FPooledObjectData — 풀 설정 레시피

```cpp
USTRUCT(BlueprintType)
struct FPooledObjectData
{
    GENERATED_BODY()

    FPooledObjectData()
    {
        ActorTemplate = nullptr;
        PoolSize = 1;
        bCanGrow = false;
        ActorName = "default";
    }

    UPROPERTY(EditAnywhere)
    TSubclassOf<AActor> ActorTemplate;  // 어떤 액터를 스폰할 것인가

    UPROPERTY(EditAnywhere)
    int32 PoolSize;                      // 몇 개를 스폰할 것인가

    UPROPERTY(EditAnywhere)
    bool bCanGrow;                       // 부족하면 추가 생성할 것인가

    UPROPERTY(EditAnywhere)
    FString ActorName;                   // 풀 식별용 이름
};
```

> [[TSubclassOf]]로 스폰할 클래스를 안전하게 지정한다.

## PooledObject — 추적 컴포넌트

각 풀링 대상 액터에 붙어서, 사용 중 여부를 체크하고 반환을 담당한다.

```cpp
UCLASS(ClassGroup=(Custom), meta=(BlueprintSpawnableComponent))
class UPooledObject : public UActorComponent
{
    GENERATED_BODY()

public:
    void Init(AMyObjectPool* Owner);

    UFUNCTION(BlueprintCallable)
    void RecycleSelf();                  // 스스로 풀에 반환

    UPROPERTY(VisibleInstanceOnly, BlueprintReadOnly)
    bool bIsPoolActive;                  // 현재 사용 중인지

private:
    TObjectPtr<AMyObjectPool> ObjectPool;

    virtual void OnComponentDestroyed(bool bDestroyingHierarchy) override;
};
```

```cpp
void UPooledObject::Init(AMyObjectPool* Owner)
{
    bIsPoolActive = false;
    ObjectPool = Owner;
}

// 풀에게 "나 반납할게" 요청
void UPooledObject::RecycleSelf()
{
    ObjectPool->RecyclePooledObject(this);
}

// 파괴될 때 델리게이트 연결을 끊어 댕글링 호출 방지
void UPooledObject::OnComponentDestroyed(bool bDestroyingHierarchy)
{
    ObjectPool->OnPoolerCleanup.RemoveDynamic(this, &UPooledObject::RecycleSelf);
    Super::OnComponentDestroyed(bDestroyingHierarchy);
}
```

> `OnComponentDestroyed`에서 언바인딩하는 이유: 파괴된 컴포넌트가 [[델리게이트]]에 묶인 채 남으면 [[댕글링 포인터와 안전한 참조|댕글링 호출]] 위험이 생긴다.

## MyObjectPool — 풀 본체

### 주요 인터페이스

```cpp
DECLARE_DYNAMIC_MULTICAST_DELEGATE(FPoolerCleanupSignature);

// 풀 하나(한 종류 액터들의 모음)
USTRUCT(BlueprintType)
struct FSingleObjectPool
{
    GENERATED_BODY()
    UPROPERTY(VisibleInstanceOnly, BlueprintReadOnly)
    TArray<TObjectPtr<UPooledObject>> PooledObjects;
};

UCLASS()
class AMyObjectPool : public AActor
{
public:
    UPROPERTY()
    FPoolerCleanupSignature OnPoolerCleanup;      // 일괄 회수 방송

    UFUNCTION(BlueprintCallable)
    void Broadcast_PoolerCleanup();               // 활성 객체 전부 회수

    UFUNCTION(BlueprintCallable)
    AActor* GetPooledActor(FString Name);         // 풀에서 꺼내기

    UFUNCTION(BlueprintCallable)
    void RecyclePooledObject(UPooledObject* PoolCompRef);  // 컴포넌트로 반환

    UFUNCTION(BlueprintCallable)
    void RecycleActor(AActor* PooledActor);       // 액터로 반환

    UPROPERTY(EditAnywhere, BlueprintReadWrite)
    TArray<FPooledObjectData> PooledObjectData;   // 레시피 목록

protected:
    UPROPERTY(VisibleAnywhere, BlueprintReadWrite)
    TArray<FSingleObjectPool> Pools;              // 실제 풀 보관소

private:
    void RegenItem(int32 PoolIndex, int32 PositionIndex);  // 빈자리 긴급 생성
};
```

### BeginPlay — 미리 생성하기

```cpp
void AMyObjectPool::BeginPlay()
{
    Super::BeginPlay();

    FActorSpawnParameters SpawnParams;
    for (int32 PoolIndex = 0; PoolIndex < PooledObjectData.Num(); PoolIndex++)
    {
        FSingleObjectPool CurrentPool;
        SpawnParams.Name = FName(*PooledObjectData[PoolIndex].ActorName);
        SpawnParams.NameMode = FActorSpawnParameters::ESpawnActorNameMode::Requested;
        SpawnParams.SpawnCollisionHandlingOverride = ESpawnActorCollisionHandlingMethod::AlwaysSpawn;

        for (int32 ObjectIndex = 0; ObjectIndex < PooledObjectData[PoolIndex].PoolSize; ObjectIndex++)
        {
            // 1. 액터 스폰 + 추적 컴포넌트 부착
            AActor* SpawnedActor = GetWorld()->SpawnActor(
                PooledObjectData[PoolIndex].ActorTemplate,
                &FVector::ZeroVector, &FRotator::ZeroRotator, SpawnParams);
            SpawnedActor->SetActorLabel(SpawnedActor->GetName());

            UPooledObject* PoolComp = NewObject<UPooledObject>(SpawnedActor);
            PoolComp->RegisterComponent();
            SpawnedActor->AddInstanceComponent(PoolComp);
            PoolComp->Init(this);
            CurrentPool.PooledObjects.Add(PoolComp);

            // 2. 비활성화 상태로 풀에 보관
            SpawnedActor->SetActorHiddenInGame(true);
            SpawnedActor->SetActorEnableCollision(false);
            SpawnedActor->SetActorTickEnabled(false);
            SpawnedActor->AttachToActor(this, FAttachmentTransformRules::SnapToTargetNotIncludingScale);
        }
        Pools.Add(CurrentPool);
    }
}
```

### 비활성화/활성화의 3요소

|함수|반납 시 (대기)|대여 시 (사용)|
|---|---|---|
|`SetActorHiddenInGame`|`true` (숨김)|`false` (보임)|
|`SetActorEnableCollision`|`false` (충돌 끔)|`true` (충돌 켬)|
|`SetActorTickEnabled`|`false` (Tick 끔)|`true` (Tick 켬)|

## GetPooledActor — 꺼내기 (대여)

흐름: **이름으로 풀 찾기 → 비활성 객체 찾기 → 활성화 + 회수 예약 → 반환**

```cpp
AActor* AMyObjectPool::GetPooledActor(FString Name)
{
    // 1. 요청한 이름의 풀 찾기
    int32 CurrentPoolIndex = -1;
    for (int32 i = 0; i < Pools.Num(); i++)
    {
        if (PooledObjectData[i].ActorName == Name)
        {
            CurrentPoolIndex = i;
            break;
        }
    }
    if (CurrentPoolIndex == -1) { return nullptr; }  // 없는 이름이면 종료

    // 2. 풀 안에서 '사용 중이 아닌' 첫 번째 객체 찾기
    int32 FirstAvailable = -1;
    for (int32 i = 0; i < Pools[CurrentPoolIndex].PooledObjects.Num(); i++)
    {
        if (Pools[CurrentPoolIndex].PooledObjects[i] != nullptr)
        {
            if (!Pools[CurrentPoolIndex].PooledObjects[i]->bIsPoolActive)
            {
                FirstAvailable = i;
                break;
            }
        }
        else  // 슬롯이 비어 있으면 긴급 생성으로 메움
        {
            RegenItem(CurrentPoolIndex, i);
            FirstAvailable = i;
            break;
        }
    }

    // 3. 찾았으면 활성화해서 반환
    if (FirstAvailable >= 0)
    {
        UPooledObject* ToReturn = Pools[CurrentPoolIndex].PooledObjects[FirstAvailable];
        ToReturn->bIsPoolActive = true;

        // 일괄 회수 방송에 등록 (회수 예약)
        OnPoolerCleanup.AddUniqueDynamic(ToReturn, &UPooledObject::RecycleSelf);

        AActor* ToReturnActor = ToReturn->GetOwner();
        ToReturnActor->SetActorHiddenInGame(false);
        ToReturnActor->SetActorEnableCollision(true);
        ToReturnActor->SetActorTickEnabled(true);

        // nullptr 부착 = 부모를 끊고 월드 최상단으로
        ToReturnActor->AttachToActor(nullptr, FAttachmentTransformRules::SnapToTargetNotIncludingScale);
        return ToReturnActor;
    }

    // 4. 전부 사용 중이면? bCanGrow가 꺼져 있으면 포기
    if (!PooledObjectData[CurrentPoolIndex].bCanGrow) { return nullptr; }

    // 5. bCanGrow가 켜져 있으면 새로 만들어서 즉시 대여 (활성 상태로 풀에 추가)
    // ... BeginPlay의 생성 로직과 동일하되, bIsPoolActive = true로 시작하고
    //     OnPoolerCleanup에 바로 등록한 뒤 반환
}
```

### 핵심 포인트

- **First Available 검색**: 선형 탐색으로 비활성 객체를 찾는 단순한 방식
- **회수 예약**: 꺼낼 때 `OnPoolerCleanup`에 `AddUniqueDynamic`으로 등록 → 나중에 방송 한 번이면 활성 객체 전부 회수됨
- **빈 슬롯 복구**: 외부에서 액터가 Destroy되어 슬롯이 nullptr이면 `RegenItem`으로 그 자리에 재생성
- **bCanGrow**: 풀이 바닥났을 때 추가 생성 허용 여부

## Recycle — 반납

```cpp
// 최종 정리 로직 (컴포넌트 기준)
void AMyObjectPool::RecyclePooledObject(UPooledObject* PoolCompRef)
{
    // 회수 방송 등록 해제 (이미 반납됐으니 또 회수할 필요 없음)
    OnPoolerCleanup.RemoveDynamic(PoolCompRef, &UPooledObject::RecycleSelf);

    PoolCompRef->bIsPoolActive = false;
    AActor* ReturningActor = PoolCompRef->GetOwner();
    ReturningActor->SetActorHiddenInGame(true);
    ReturningActor->SetActorEnableCollision(false);
    ReturningActor->SetActorTickEnabled(false);

    // 다시 풀 본체에 부착해서 보관
    ReturningActor->AttachToActor(this, FAttachmentTransformRules::SnapToTargetNotIncludingScale);
}

// 액터 기준 반납 (외부/블루프린트용 편의 함수)
void AMyObjectPool::RecycleActor(AActor* PooledActor)
{
    if (UPooledObject* PoolCompRef = Cast<UPooledObject>(
        PooledActor->GetComponentByClass(UPooledObject::StaticClass())))
    {
        RecyclePooledObject(PoolCompRef);
    }
}

// 활성 객체 일괄 회수 (방송 한 번으로 전부 반납)
void AMyObjectPool::Broadcast_PoolerCleanup()
{
    OnPoolerCleanup.Broadcast();
}
```

### 대여/반납 사이클 요약

```
GetPooledActor(이름)
  → bIsPoolActive = true
  → OnPoolerCleanup에 회수 예약 (AddUniqueDynamic)
  → 보이기/충돌/Tick 켜고 부모 분리
        ↓ (사용)
RecycleSelf() 또는 RecycleActor() 또는 Broadcast_PoolerCleanup()
  → 회수 예약 해제 (RemoveDynamic)
  → bIsPoolActive = false
  → 숨기기/충돌/Tick 끄고 풀에 재부착
```

> 레벨 종료나 페이즈 전환 때 `Broadcast_PoolerCleanup()` 한 번이면 나가 있는 객체가 전부 돌아온다. [[델리게이트]]의 멀티캐스트가 빛나는 지점.

## RegenItem — 빈자리 긴급 생성

풀 슬롯의 객체가 외부에서 Destroy되어 nullptr이 된 경우, 그 인덱스에 새 객체를 만들어 메운다.

```cpp
void AMyObjectPool::RegenItem(int32 PoolIndex, int32 PositionIndex)
{
    // BeginPlay와 동일한 생성 과정
    AActor* SpawnedActor = GetWorld()->SpawnActor(...);
    UPooledObject* PoolComp = NewObject<UPooledObject>(SpawnedActor);
    PoolComp->RegisterComponent();
    SpawnedActor->AddInstanceComponent(PoolComp);
    PoolComp->Init(this);

    // 해당 인덱스 자리에 삽입
    Pools[PoolIndex].PooledObjects.Insert(PoolComp, PositionIndex);

    // 비활성 상태로 보관
    SpawnedActor->SetActorHiddenInGame(true);
    SpawnedActor->SetActorEnableCollision(false);
    SpawnedActor->SetActorTickEnabled(false);
    SpawnedActor->AttachToActor(this, FAttachmentTransformRules::SnapToTargetNotIncludingScale);
}
```

## 풀을 어디에 둘까?

오브젝트 풀링 구현 위치는 상황에 따라 선택:

|위치|특징|
|---|---|
|**월드에 매니저 액터 배치**|이번 실습 방식. 직관적, 에디터에서 레시피 설정 편함|
|**[[서브시스템\|월드 서브시스템]]**|레벨 수명에 맞춰 자동 생성/정리, 배치 불필요|
|**레벨 스크립트 액터**|레벨 블루프린트에서 직접 관리|
|**게임모드에 컴포넌트**|게임 규칙과 함께 관리|
