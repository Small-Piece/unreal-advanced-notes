# 서브시스템

> 내가 직접 만들고 관리하지 않아도, 엔진이 정해진 수명에 맞춰 자동으로 켜고 꺼주는 시스템.

---

## 왜 쓰나?

기존에는 매니저를 Actor나 GameInstance로 만들어서 **직접 생성하고 직접 제거**해야 했다. 안 쓰는 정보도 수동으로 지워야 했고.

서브시스템은 **특정 수명을 가진 클래스**를 상속받아 쓰면, 정해진 시점에 자동 생성되고 수명이 끝나면 자동으로 메모리에서 치워진다.

### 장점

- 게임 로직을 GameInstance에 다 욱여넣지 않고 기능별(통계, UI 관리 등)로 파일을 분리 → 코드가 깔끔
- `NewObject`로 생성하고 [[가비지 컬렉션]]을 걱정할 필요 없음. 엔진이 생명주기를 책임짐
- 플러그인에 넣기만 하면 자동 활성화

---

## 수명별 종류

|종류|상속 클래스|생성 시점|소멸 시점|
|---|---|---|---|
|**Engine**|`UEngineSubsystem`|프로그램 실행|프로그램 종료|
|**Editor**|`UEditorSubsystem`|에디터 켜질 때|에디터 꺼질 때|
|**GameInstance**|`UGameInstanceSubsystem`|게임 시작|게임 프로세스 종료|
|**World** (UE5 추가)|`UWorldSubsystem`|레벨 로드 시|레벨 전환/언로드 시|
|**LocalPlayer**|`ULocalPlayerSubsystem`|플레이어 접속 시|플레이어 퇴장 시|

## Initialize / Deinitialize

```cpp
virtual void Initialize(FSubsystemCollectionBase& Collection) override;
virtual void Deinitialize() override;
```

```cpp
void UMyWorldSubsystem::Initialize(FSubsystemCollectionBase& Collection)
{
    Super::Initialize(Collection);
    // 변수 초기화, 델리게이트 바인딩
}

void UMyWorldSubsystem::Deinitialize()
{
    // 메모리 해제, 델리게이트 언바인딩, 파일 저장
    Super::Deinitialize();
}
```

|함수|호출 시점|할 일|
|---|---|---|
|`Initialize`|객체 생성 직후|변수 초기화, [[델리게이트]] 바인딩|
|`Deinitialize`|파괴 직전|메모리 해제, 언바인딩, 저장|

## ShouldCreateSubsystem — 조건부 생성

```cpp
virtual bool ShouldCreateSubsystem(UObject* Outer) const override;
```

true면 생성, false면 생성 안 함. 활용 예:

- **서버 전용 시스템**: 서버는 true, 클라이언트는 false
- **특정 맵 전용 시스템**: 보스 레이드 타이머처럼 특정 맵에서만

```cpp
bool UMyWorldSubsystem::ShouldCreateSubsystem(UObject* Outer) const
{
    UWorld* World = Cast<UWorld>(Outer);
    return (World && World->GetMapName().Contains(TEXT("StarterMap")));
}
```

### Outer 매개변수

"누가 나를 관리하고 있나"를 받아오는 것. 상속한 서브시스템 종류에 따라 주인이 다르다:

|서브시스템|Outer (주인)|`Cast<T>(Outer)`|
|---|---|---|
|Engine|`GEngine`|`UEngine*`|
|GameInstance|`UGameInstance`|`UGameInstance*`|
|World|`UWorld`|`UWorld*`|
|LocalPlayer|`ULocalPlayer`|`ULocalPlayer*`|

## 서브시스템 가져오기

### C++ — 형변환 없이 바로

```cpp
UMyWorldSubsystem* MySub = GetWorld()->GetSubsystem<UMyWorldSubsystem>();
FString Name = MySub->MyTestName;

// GameInstance 서브시스템이라면
UItemManagerSubsystem* ItemManager = GetGameInstance()->GetSubsystem<UItemManagerSubsystem>();
```

블루프린트에서는 노드로 더 간단히 가져올 수 있다.

## 서브시스템 간 의존성

서브시스템도 다른 서브시스템이 필요할 수 있다. 예: WeatherSubsystem이 시간을 알아야 해서 TimeSubsystem이 필요한데, **날씨가 먼저 생성되면 에러**.

`Initialize`의 `Collection` 매개변수로 **선행 초기화를 보장**한다:

```cpp
void UWeatherSubsystem::Initialize(FSubsystemCollectionBase& Collection)
{
    Super::Initialize(Collection);

    // "TimeSubsystem이 있으면 걔부터 먼저 초기화시켜줘" → 의존성 주입
    UTimeWorldSubsystem* TimeSub = Collection.InitializeDependency<UTimeWorldSubsystem>();

    if (TimeSub)
    {
        int32 CurrentHour = TimeSub->GetCurrentHour();  // 안전하게 참조 가능
    }
}
```
