# 리플렉션

> 프로그램이 실행 중에 자기 자신의 구조(클래스, 변수, 함수)를 스스로 인지하고 조작하는 능력

---

## 비유: 자기소개를 할 수 있는 능력

일반 C++의 객체는 "너 누구야?"라고 물어보면 대답을 못 한다. 하지만 언리얼의 리플렉션 시스템이 있으면 객체가 이렇게 대답할 수 있다:

- "나는 `AMyActor`라는 클래스야"
- "나한테 `Health`라는 int32 변수가 있어"
- "`TakeDamage`라는 함수도 있어. 실행해볼래?"

---

## 리플렉션이 하는 구체적인 일

### 1. 런타임 타입 정보 확인

게임이 돌아가는 도중에 특정 객체가 어떤 클래스인지, 어떤 부모를 가졌는지 확인한다.

```cpp
// 이 객체가 AMyActor인지 확인
if (SomeObject->IsA<AMyActor>())
{
    // AMyActor 맞다!
}
```

### 2. 에디터 연동

[[UPROPERTY]]를 붙인 변수는 엔진이 그 이름과 자료형을 기억한다. 덕분에 코드를 고치지 않아도 언리얼 에디터 디테일 패널에 변수 칸이 자동으로 생기고, 값을 입력할 수 있게 된다.

### 3. 가비지 컬렉션

엔진이 "이 변수는 UObject를 가리키고 있다"는 것을 리플렉션을 통해 알고 있기 때문에, [[가비지 컬렉션]]이 동작할 수 있다. 아무도 참조하지 않는 객체를 찾아내서 안전하게 메모리에서 지운다.

---

## 리플렉션을 가능하게 만드는 매크로들

| 매크로 | 역할 |
|---|---|
| [[UFUNCTION과 UCLASS\|UCLASS()]] | 클래스를 엔진에 등록 |
| [[UPROPERTY\|UPROPERTY()]] | 변수를 엔진에 등록 |
| [[UFUNCTION과 UCLASS\|UFUNCTION()]] | 함수를 엔진에 등록 |

이 매크로들이 붙은 코드를 [[UHT (Unreal Header Tool)]]가 스캔해서 `.generated.h` 파일을 만들고, 이 파일이 리플렉션 정보를 담고 있다.
