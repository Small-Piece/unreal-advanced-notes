# CDO (Class Default Object)

> 모든 UObject 클래스가 메모리에 딱 하나씩 갖고 있는 원본 객체. 해당 클래스의 모든 기본값을 보관한다.

---

## 비유: 붕어빵 틀

- **CDO** = 붕어빵 틀 (원본, 딱 하나)
- **인스턴스** = 틀에서 찍어낸 붕어빵 (여러 개)
- 붕어빵 하나에 초코를 넣어도 틀이 바뀌지 않음
- 틀을 억지로 바꿔도 이미 만들어진 붕어빵은 그대로

---

## 생성 시점

[[빌드 타임라인]]에서 엔진 초기화 단계, 즉 에디터가 켜지거나 게임이 시작되기 **훨씬 전**에 만들어진다.

```
UBT → UHT → 컴파일 → ⭐ 엔진 초기화 (CDO 생성) → 에디터/게임 시작
```

엔진이 각 클래스의 **생성자를 딱 한 번 호출**해서 CDO를 완성한다. 생성자에 적은 초기화 로직이 바로 이때 실행된다.

```cpp
AMyActor::AMyActor()
{
    // 이 값들이 CDO에 기록됨
    MoveSpeed = 600.0f;
    bCanDash = true;
    MaxHealth = 100;
}
```

### ⚠️ 생성자에서 하면 안 되는 것

CDO는 엔진 초기화 **초기 단계**에서 만들어지므로, 생성자에서는:

- `GetWorld()` 호출 ❌ — World가 아직 없을 수 있음
- 다른 액터 참조 ❌ — 아직 생성 안 됐을 수 있음
- 게임 로직 실행 ❌ — 게임이 시작된 게 아님

→ 이런 것들은 **BeginPlay()** 에서 해야 한다.

---

## 복제 방식: 왜 빠른가?

게임 중 액터를 스폰할 때, 엔진은 생성자를 다시 실행하지 않는다.

| CDO 없는 세상 | CDO 있는 세상 |
|---|---|
| 총알 하나마다 생성자 코드를 처음부터 끝까지 실행 | CDO 메모리를 통째로 복사 → 끝 |
| 1000발 = 생성자 1000번 실행 | 1000발 = 메모리 복사 1000번 (훨씬 빠름) |

---

## 최적화 효과 (TA 관점에서 중요)

### 1. 메모리 절약

총알 1000개가 전부 `Damage = 10`이라는 기본값을 가져도, 이 값을 1000번 저장하지 않는다. CDO 하나에만 저장하고, 개별 인스턴스는 **기본값과 달라진 부분만** 따로 저장한다.

### 2. 빠른 초기화

런타임에 클래스 정보를 일일이 뒤질 필요 없이, CDO를 통해 즉각적으로 타입 체크나 기본값 참조가 가능하다.

### 3. 델타 직렬화 (Delta Serialization)

세이브하거나 네트워크로 전송할 때, 객체의 모든 정보를 보내지 않는다. **CDO와 비교해서 바뀐 부분(차이점)만** 기록하고 전송한다.

- 세이브 파일 용량 감소
- 네트워크 패킷 크기 감소 → 멀티플레이 최적화 핵심

## 실험: CDO vs 인스턴스

```cpp
// 1. 인스턴스 생성 → CDO에서 복사 → Health = 100
AMyActor* ActorA = GetWorld()->SpawnActor<AMyActor>();
// ActorA->Health == 100

// 2. 인스턴스만 수정
ActorA->Health = 50;
// ActorA->Health == 50, CDO->Health == 100 (원본 무관)

// 3. CDO 직접 확인
AMyActor* CDO = GetMutableDefault<AMyActor>();
// CDO->Health == 100 (인스턴스를 바꿔도 원본은 그대로!)

// 4. CDO를 억지로 수정 (⚠️ 위험! 교육용!)
CDO->Health = 200;

// 5. 새 인스턴스 생성
AMyActor* ActorB = GetWorld()->SpawnActor<AMyActor>();
// ActorB->Health == 100 (엔진이 CDO 직접 수정을 방어함)

// 6. 기존 인스턴스
// ActorA->Health == 50 (이미 태어난 건 영향 없음)
```

---

## CDO 접근 방법

```cpp
// 읽기 전용 (const) — 안전
const AMyActor* CDO = GetDefault<AMyActor>();

// 수정 가능 — ⚠️ 런타임에 쓰지 말 것
AMyActor* MutableCDO = GetMutableDefault<AMyActor>();
```
