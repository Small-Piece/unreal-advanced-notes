# UBT (Unreal Build Tool)

> 프로젝트의 모듈과 플러그인을 확인하고, 현재 플랫폼에 맞는 빌드 환경을 세팅하는 도구

---

## 비유: 현장 감독

건물을 짓기 전에 현장 감독이 먼저 와서 확인한다:

- "이 현장에 어떤 자재(모듈)가 필요하지?"
- "어떤 장비(플러그인)를 쓰지?"
- "여기가 Windows 현장이야, Mac 현장이야?"

---

## 하는 일

1. **모듈/플러그인 확인** — `.Target.cs`와 `.Build.cs` 파일을 읽어서 프로젝트가 어떤 모듈과 플러그인을 사용하는지 파악
2. **플랫폼별 환경 세팅** — Windows인지 Mac인지 판단해서 모듈과 플러그인을 해당 환경에 맞게 변환. 덕분에 같은 프로젝트를 어디서든 동일하게 열 수 있음
3. **헤더 변경 감지** — 헤더 파일이 바뀌면 [[UHT (Unreal Header Tool)]]를 실행시킴
4. **라이브 코딩 지원** — cpp 파일만 바뀌면 백그라운드에서 UBT가 가볍게 실행됨

---

## 관련 파일들

| 파일 | 역할 |
|---|---|
| `{프로젝트}.Target.cs` | 게임 빌드 타겟 설정 |
| `{프로젝트}Editor.Target.cs` | 에디터 빌드 타겟 설정 |
| `{프로젝트}.Build.cs` | 모듈 의존성, 사용할 모듈 정의 |

---

## 빌드 흐름에서의 위치

[[빌드 타임라인]]에서 UBT는 **가장 먼저** 실행된다:

```
UBT (환경 세팅) → UHT (리플렉션 코드 생성) → 컴파일러 (코드 빌드)
```

---

## 관련 노트

- [[UHT (Unreal Header Tool)]] — UBT가 헤더 변경을 감지하면 실행시키는 도구
- [[빌드 타임라인]] — 전체 빌드 과정
