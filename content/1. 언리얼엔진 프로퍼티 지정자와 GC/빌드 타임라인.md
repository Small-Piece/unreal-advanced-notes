# 빌드 타임라인

> 코드를 작성한 뒤 엔진이 실행되기까지의 전체 과정

---

## 비유: 신입생 등교 과정

| 단계 | 비유 | 실제 |
|---|---|---|
| 1 | 현장 감독이 학교 시설 점검 | [[UBT (Unreal Build Tool)]]가 모듈/플러그인 확인, 플랫폼별 환경 세팅 |
| 2 | 신분증 발급소에서 학생증 발급 | [[UHT (Unreal Header Tool)]]가 매크로 스캔 → `.generated.h` 생성 |
| 3 | 선생님이 학생증 읽고 출석부 작성 | 컴파일러(Visual Studio)가 코드 빌드. `#include "*.generated.h"`와 `GENERATED_BODY()` 처리 |
| 4 | 학교 시스템에 학생 등록 완료 | [[리플렉션]] 완성! 엔진이 클래스/변수/함수를 인식 |
| 5 | 각 학생의 기본 프로필 생성 | [[CDO (Class Default Object)]] 생성. 생성자가 딱 한 번 호출됨 |

---

## 상세 흐름

```
┌─────────────────────────────────────────────┐
│  1. UBT 실행                                 │
│     .Target.cs / .Build.cs 읽기              │
│     모듈, 플러그인, 플랫폼 확인                  │
│     "헤더 바뀌었네?" → UHT 실행 결정            │
└──────────────┬──────────────────────────────┘
               ▼
┌─────────────────────────────────────────────┐
│  2. UHT 실행                                 │
│     UCLASS, UPROPERTY, UFUNCTION 스캔        │
│     메타데이터 수집                            │
│     MyActor.generated.h 생성                 │
└──────────────┬──────────────────────────────┘
               ▼
┌─────────────────────────────────────────────┐
│  3. 컴파일러 (Visual Studio / Rider)          │
│     헤더 순서대로 읽기                          │
│     #include "*.generated.h" 처리             │
│     GENERATED_BODY() 매크로 확장               │
│     → 리플렉션 완성!                           │
└──────────────┬──────────────────────────────┘
               ▼
┌─────────────────────────────────────────────┐
│  4. 엔진 초기화                               │
│     모듈 로딩                                 │
│     각 클래스의 생성자 호출 (딱 한 번)            │
│     → CDO 생성 완료!                          │
└──────────────┬──────────────────────────────┘
               ▼
┌─────────────────────────────────────────────┐
│  5. 에디터 / 게임 시작                         │
│     CDO를 복사해서 인스턴스 생성                 │
│     BeginPlay() 호출                         │
└─────────────────────────────────────────────┘
```

## 수정 시 재빌드 범위

### CPP만 수정한 경우

```
(UBT 백그라운드 실행) → 컴파일러 → 라이브 코딩 반영 ✅ 빠름
```

UHT를 다시 돌릴 필요가 없다. 신분증(`.generated.h`)은 이미 만들어져 있으니까.

### 헤더를 수정한 경우

```
UBT → "헤더 바뀌었네!" → UHT 재실행 → 컴파일러 → 전체 리빌드 ⚠️ 느림
```

신상 정보가 바뀌었으니 신분증을 다시 발급해야 한다.

> **팁**: 그래서 변수 초기값은 헤더가 아닌 생성자(CPP)에서 설정하는 것이 좋다. 헤더를 안 건드리면 라이브 코딩으로 끝난다.
