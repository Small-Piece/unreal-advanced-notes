# 🎮 언리얼 엔진 심화 개념 MOC

> UE5 C++ 심화 개념을 정리한 노트입니다. 각 노트를 클릭하며 개념 간 연결을 탐색해 보세요.

---

## 🔧 빌드 시스템

엔진이 코드를 읽고 실행하기까지의 과정

- [[UBT (Unreal Build Tool)]] — 빌드 환경을 세팅하는 현장 감독
- [[UHT (Unreal Header Tool)]] — 리플렉션 코드를 생성하는 신분증 발급소
- [[빌드 타임라인]] — UBT → UHT → 컴파일 → 엔진 초기화 전체 흐름

## 🪞 리플렉션 시스템

엔진이 클래스와 변수를 "인식"하는 구조

- [[리플렉션]] — 프로그램이 자기 자신을 인지하는 능력
- [[UPROPERTY]] — 변수를 엔진에 등록하는 매크로
- [[UFUNCTION과 UCLASS]] — 함수와 클래스를 엔진에 등록하는 매크로

## 🗑️ 메모리 관리

엔진이 메모리를 자동으로 관리하는 방법

- [[가비지 컬렉션]] — 안 쓰는 객체를 자동으로 치우는 청소부
- [[댕글링 포인터와 안전한 참조]] — 삭제된 메모리를 잘못 접근하는 위험과 해결법

## 🏭 객체 생성과 수명 관리

인스턴스가 만들어지고 관리되는 원리

- [[CDO (Class Default Object)]] — 모든 인스턴스의 원본이 되는 붕어빵 틀
- [[서브시스템]] — 엔진이 정해진 수명에 맞춰 자동 관리하는 시스템
- [[오브젝트 풀링]] — 생성/삭제 대신 재사용하는 최적화 패턴

## 🔗 UE5 포인터 타입

UE5에서 객체와 클래스를 안전하게 다루는 방법

- [[TObjectPtr]] — UE5의 스마트 핸들. 지연 로딩과 액세스 트래킹 제공
- [[TSubclassOf]] — 클래스 타입을 안전하게 담는 필터링된 바구니

## 📦 컨테이너

데이터를 효율적으로 저장하고 관리하는 자료구조

- [[언리얼 컨테이너 개요]] — TArray, TSet, TMap 비교 및 선택 기준
- [[TArray]] — 순서가 있는 배열, 인덱스 접근 O(1)
- [[TSet]] — 중복 없는 집합, 탐색 O(1)
- [[TMap]] — Key-Value 쌍, 키로 즉시 검색

## 💾 메모리 최적화와 데이터 관리

무거운 에셋을 효율적으로 로드하고 데이터를 관리하는 방법

- [[에셋 참조와 소프트 포인터]] — 하드/소프트 참조, 동기/비동기 로드
- [[데이터 관리 - DataTable과 DataAsset]] — 데이터 저장 방식과 AssetManager
- [[아이템 매니저 실전 예시]] — 서브시스템 + DataAsset + 델리게이트 종합

## 💥 콜리전과 전투 시스템

충돌 판정부터 데미지 적용까지의 전체 흐름

- [[콜리전 시스템]] — 오브젝트 채널, 프리셋, 단순/복합 콜리전
- [[콜리전과 Trace]] — Single, Multi, 비동기 Trace 실습
- [[데미지 시스템]] — ApplyDamage, TakeDamage, 커스텀 DamageType

## 🧹 코드 설계와 디자인 패턴

유지보수하기 좋은 코드 구조와 실전 설계 패턴

- [[코드 스멜과 리팩토링]] — 9가지 코드 스멜

## 개념 연결 요약

```
UBT → UHT → 컴파일러 → 엔진 초기화 → CDO 생성
                ↓
         리플렉션 (.generated.h)
                ↓
      UPROPERTY / UFUNCTION / UCLASS
           ↓              ↓
    에디터 연동      가비지 컬렉션 ←──── 오브젝트 풀링
         ↓              ↓              (GC 부하 자체를 줄임)
    TObjectPtr      댕글링 포인터 방지
    TSubclassOf          ↑
         ↓               │ (수명 자동 관리)
   TArray/TSet/TMap   서브시스템
         ↓               ↓
   ┌─────────────┬───────┴────────┬──────────┐
   ↓             ↓                ↓          ↓
콜리전→Trace    소프트 포인터      아이템      코드 설계
   →데미지      →DataTable        매니저      (스멜/패턴/
   ↓            /DataAsset        (통합 예시)  인터페이스/
DamageType      +AssetManager                델리게이트)
(CDO 참조)
```
